快速、极简的前端资源 CDN

alyjs.com/npm包名@版本/文件路径

为开发者而生，毫秒级响应

快速开始

在您的 HTML 中直接引用任意 npm 包中的文件，无需构建工具。

<script src="https://alyjs.com/jquery@3.7.1/dist/jquery.min.js"></script> <link rel="stylesheet" href="https://alyjs.com/bootstrap@5.3.0/dist/css/bootstrap.min.css">

特性

  • 全球 CDN 加速，毫秒级加载
  • 自动处理 package.json 中的 main / module 入口
  • 支持语义化版本范围 (^1.0.0, ~2.1.x)
  • 启用 Brotli & Gzip 压缩
  • 强缓存策略，最大化加载速度
  • 永久托管，已发布的版本不会删除

URL 结构

参数 说明
:package npm 包名称
@:version 版本号或语义化范围（可选）
/:file 包内的文件路径（可选）

常用示例

获取包的最新版本：

https://alyjs.com/react

指定版本：

https://alyjs.com/react@18.2.0

获取包内文件：

https://alyjs.com/vue@3.4.0/dist/vue.global.prod.js

查看目录列表：

https://alyjs.com/lodash@4.17.21/
